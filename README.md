El taller explica React frente a JSX, componentes de clase, eventos y un mapa conceptual.

## Cómo abrir los apoyos

Descargar y descomprimir el ZIP. La carpeta `apoyo` contiene `index.html`, `demo.js`, el mapa SVG y dos ejemplos JSX. Abrir `index.html` en un navegador con internet para cargar React y ReactDOM 18.3.1 desde jsDelivr.

La demostración usa datos ficticios y estado en memoria. No conecta a Spring Boot ni guarda información al recargar. Los ejemplos JSX requieren un entorno React con transformación de JSX.
